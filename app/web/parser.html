document_scanner

Parser & Docling

Converte PDFs/DOCX de editais em Markdown segmentado com referências de página para citação em peças (compliance Lei 14.133).

Fluxo

  1. Baixar anexos: POST /ingestion/pncp/{id}/documents
  2. Arquivos em data/raw/{id_licitacao}
  3. Parse Docling: POST /parser/{id}
  4. Seções mapeadas para TenderSchema

Engines

  • Docling (preferencial, OCR local)
  • Fallback PDF text extraction
